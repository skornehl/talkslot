Free and open source · AGPL v3

Parent-teacher conferences, booked in a minute.

Teachers publish their time slots, parents pick one. No account, no app, no cookies. Built for schools that care about privacy, and simple enough to run on a basic web host.

One tool, four happy groups

TalkSlot replaces paper lists, e-mail ping-pong and spreadsheets. Everybody gets exactly what they need, and nothing more.

Parents

  • Open a link or enter a short round code
  • Pick a free slot, enter a name: done
  • Language choice at the top of every page, in six languages
  • Move or cancel with a personal link
  • Confirmation with calendar file and a reminder the evening before (optional)
  • An e-mail in their language when the teacher moves or cancels the appointment
{% include icon-teachers.svg %}

Teachers

  • Rounds with several days, breaks, location and live preview
  • See who booked when, move or add bookings
  • Change or cancel days and appointments, parents are told by e-mail
  • Templates, invitation text with a direct link per language, print lists
  • Summary mail the evening before: the number of appointments and anything worth a look, no names unless the school allows them
{% include icon-schools.svg %}

Schools

  • Several admins invite teachers, see all rounds, with a log and security mails
  • Imprint and privacy policy templates (GDPR) for both operator types: run by the school or privately
  • Bookings are deleted the day after the meeting
  • No tracking, no external services
{% include icon-operators.svg %}

Operators

  • Runs on shared hosting with PHP 8.3+ and MariaDB 10.6+, and says plainly what the server or the configuration lacks
  • Zero-downtime deployment via GitHub Actions
  • Automatic migrations; rollback by itself if the site or its database fails the check, or in one click
  • Error alerts by mail, also when the cron job stops, without personal data
  • Mail queue with retries: reminders and summaries sent by the cron job, undelivered mails shown to admins

Booking without friction

Parents only see free slots. They enter a name (and an e-mail address if they want a confirmation) and get a personal link to move or cancel the appointment later.

  • Readable link per round, or an 8-character round code for paper invitations
  • One booking per person per round or per day, if the teacher wants it
  • Optional "round code required" protection against strangers
  • Calendar file that updates itself when the appointment is moved
  • Personal link easy to keep: copy, add to the calendar or get the confirmation by e-mail afterwards
  • No dead ends: the page says why no slot is free, shows whom to ask, and a wrong link leads to the code input

Everything a teacher needs, on one page

Each round shows its link, round code and invitation text, then every day with its breaks and all bookings. Slots can be blocked, bookings edited, moved or added by hand. Before deleting and when a day is moved, dialogs and hints say clearly that the parents still need to be told.

  • Changing times never deletes a booking; conflicts are flagged
  • Deleting a round with bookings needs an extra tick; expired rounds show when they will be deleted, drafts are kept
  • Print view per round or day, also as PDF
  • Titles and descriptions translated in the teacher's browser, without sending text anywhere

Light and dark, on every device

TalkSlot follows the device setting and can be switched in the footer. Pages are accessible, keyboard-friendly and work well on small screens.

Privacy is the default, not an option

TalkSlot was built for German schools, so it follows the GDPR and the German TDDDG closely. The same choices protect parents everywhere.

Data minimisation

A free-text name and an optional e-mail address. That is all TalkSlot stores about parents.

No cookies, no banner

Public pages set no cookies and load nothing from third parties. Language and CSRF protection work without them.

Automatic deletion

Bookings are deleted from midnight after the appointment, rate-limit data after 24 hours, finished rounds a day after their last date.

Ready-made legal texts

Imprint and privacy policy templates in German and English, for running TalkSlot as the school or privately (a person, association or independent provider whose service teachers use). You choose the operator type at installation, the templates follow it and are filled in with the operator's details. Rounds only go live once no placeholder is left. Edited texts are never overwritten: when a template changes, admins see which sections changed and take them over.

Documents for your records

Templates for the record of processing, technical and organisational measures, the DPIA check, data breaches, requests of data subjects and an information sheet for teachers, for a school or a private operator. See the templates.

Try it in two minutes

The repository contains a Docker setup with database and mail catcher, plus demo data.

Getting started guide 
git clone https://github.com/skornehl/talkslot.git
cd talkslot
cp dev/config.dev.php config/config.php
docker compose -f dev/compose.yml up -d --build
dev/reset.sh && dev/demo.sh
